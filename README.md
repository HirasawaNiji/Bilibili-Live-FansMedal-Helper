# 环境要求

- 浏览器：推荐使用 Chrome, Edge, Firefox, Safari 或 Opera。
- 用户脚本管理器：推荐使用 [Tampermonkey](https://www.tampermonkey.net) 或 [Violentmonkey](https://violentmonkey.github.io)。



## 与原版的主要区别

- 观看直播任务只处理当前正在直播的主播。
- 未开播主播进入等待队列，开播后自动开始观看。
- 点亮熄灭粉丝牌只使用点赞，不自动发送弹幕。
- 新增储蓄亲密度 90+ 提醒。
- 提醒列表显示主播当前开播状态。
- 不会自动投喂付费粉丝灯牌或消耗电池。
